# gate
낡은 석문 앞에 섰다. 안쪽에서 찬 바람이 올라온다.
문은 반쯤 열려 있고, 바닥에는 누군가 흘린 횃불 자국이 남아 있다.
(장면 '입구'의 첫 에피소드다. 고른 선택지가 스탯을 바꾼다.)

# fork
통로가 셋으로 갈라진다.
아래로 이어지는 깊은 길, 녹슨 자물쇠가 걸린 옆문, 그리고 지나온 길.
(같은 장면 '입구'의 두 번째 에피소드다. 깊은 길은 용기 2가 있어야 열리고, 옆문은 열쇠가 있어야 보인다.)

# depth
발밑의 계단이 끝없이 이어진다. 횃불이 흔들린다.
(새 장면 '깊은 곳'. 장면 경계를 넘을 때마다 앞 장면이 확정된다.)
(다음 에피소드 '바닥'으로는 묻지 않고 자동으로 간다. 자동 간선은 같은 장면 안에서만 쓸 수 있다.)

# floor
계단 끝, 물이 고인 넓은 방에 닿았다. 더 내려갈 길은 오늘은 보이지 않는다.
(같은 장면 '깊은 곳'의 두 번째 에피소드. 다음 간선이 없으니 챕터가 끝난다.)
(EventKey가 붙은 에피소드라, 장면이 확정될 때 이벤트 목록에 오른다.)

# vault
자물쇠가 힘없이 풀린다. 먼지 쌓인 선반에 오래된 지도가 놓여 있다.
(새 장면 '보관실'. 장면을 나가는 길은 자동 간선으로 둘 수 없어 항상 묻는 선택지다.)
(EventKey가 붙은 에피소드라, 장면이 확정될 때 이벤트 목록에 오른다.)

# return
오늘은 여기까지다. 입구를 등지고 걸음을 돌린다.
(다음 간선이 없는 에피소드에서 챕터가 끝난다.)

# end
지도를 펼치자 다음 층으로 가는 길이 보인다.
(챕터 끝. [처음부터]로 다른 길을 골라 볼 수 있다.)
